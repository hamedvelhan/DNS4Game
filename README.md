# DNS Game Art

پیش‌نمایش وب رابط DNS Game Art (React + Vite + TypeScript).

## اجرا

```bash
npm install
npm run dev
```

## ساختار

- خانه: اتصال/قطع ترکیبی، داشبورد بعد از اتصال
- سرورها: اسکن هوشمند + انتخاب سرور با تبلیغ خودکار
- حساب: اشتراک و خریدها
- تنظیمات

هر اتصال رایگان ۶۰ دقیقه است. دو ویدیوی جایزه‌ای = +۶۰ دقیقه.
